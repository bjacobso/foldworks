# Foldworks brand assets

This directory contains the scoped Foldworks icon and logo set rebuilt from the
original inspiration board.

## Contents

- `source/foldworks-inspiration.png` — the original, unmodified brand-board
  inspiration supplied for the rebuild.
- `source/foldworks-logo-inspiration.png` — the original, unmodified close-up
  logo inspiration used to refine the horizontal lockup.
- `svg/foldworks-icon.svg` — the supplied standalone vector mark, retained as
  the canonical geometry source.
- `svg/foldworks-icon-light.svg` — app icon for light themes.
- `svg/foldworks-icon-dark.svg` — app icon for dark themes.
- `svg/foldworks-logo-light.svg` — horizontal logo for light themes.
- `svg/foldworks-logo-dark.svg` — horizontal logo for dark themes.
- `png/` — high-resolution PNG exports matching those four SVG variants.

The SVGs are the canonical assets. The horizontal logos use Noto Sans Black,
with Arial and Helvetica fallbacks, so the wordmark remains editable; convert
the text to outlines before sending artwork to a printer or another environment
where font substitution is unacceptable.

The mark is constructed as three named vector panels: the cyan `stem`, the
upper `top-arm`, and the shorter `middle-arm`. A soft crease shadow between the
stem and middle arm preserves the folded, angled F shape at larger sizes.
